## Lewes, Anglers Road

One states length, beam, and a Coast Guard passenger limit. The other states no length. A shared banner names both labels and does not say they are one hull, so they were not joined. Both stay held.

One operator home page states a length and a builder. A commercial vessel index uses a similar builder name and a different length, and it hides the hailing port unless a membership is purchased. The page chrome says data were updated on November 9, 2017, including on the disclaimer, so that banner is not a measurement date for one hull. The records were not joined. The DNREC Lewes sentence names the boat and adds no dimensions. That row stays held.

The other operator home page states a length, a passenger limit, and a former name. No second publisher was opened. The former name was not counted as a second hull. That row stays held. A marketplace snippet that repeated a length was not fetched.

None of these rows match the four inventory observations. Those IDs were not reused.
