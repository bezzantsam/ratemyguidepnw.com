# How we counted

Define the source population before counting. Use the landing’s designated fishing roster or declare a bounded operator sample. Deduplicate repeated website navigation and record extra fleet-body entries separately. A fishing offer needs direct operating or booking evidence. A vessel match also needs evidence distinguishing the physical hull. Check dates reflect when we read the sources.

For every private observation record the publisher, URL, source date if known, and check date. Keep captain, vessel, operator, booking desk, home port and departure in separate fields. Retain a stable hull identity across an evidenced captain change. A replacement boat gets a different identity. An unresolved cross-fleet match goes to review.

A landing and a separate operator can corroborate one another. Two pages on an operator’s site share one publisher. State each count with its evidence type. Permission to copy or redistribute is source-specific. Where we found no applicable terms, the status is unknown. The public files contain source links and aggregate findings. Local working records retain the supporting observations.
