# Indiana fishing-guide inventory

Checked 2026-11-25. Scope is the Indiana fishing-guide license and Lake Michigan charters that depart from Michigan City. This note is methodology, aggregate counts, primary-source links, and unresolved permission questions. It does not identify operators or people.

## Credential

Indiana Code 14-22-15, as compiled in the Division of Fish and Wildlife regulations PDF, requires an individual to hold a fishing guide license from the director before taking another individual sport fishing for hire on Indiana waters, waters containing state-owned fish, or boundary waters of Indiana. The license is issued to a person. It is valid for one year and expires December 31. The same chapter sets a statutory annual fee of $100 for a resident or a nonresident.

The current application, State Form 25298 (R6/6-22), and the Division permits table both state a $125 fee and point at IC 14-22-15-2 together with IC 14-10-2-1. The register page that would show the adopted fee rule did not return section text on this check, so the step from $100 to $125 is not quoted from the rule here.

The same regulations PDF includes 312 IAC 9-7-17. The rule also places the license on an individual. A license holder keeps daily catch records and files a monthly report by the 15th, including months with no trips, unless an inactive-license form was filed. One sentence in that Division PDF is garbled. The official register rendering of the rule was not retrieved.

The license is not a vessel credential. The application asks whether a boat will be used and, if so, collects a boat name and a registration number. Those fields are not on the public list. Bank guiding without a boat still requires the license. A separate passenger-for-hire watercraft line appears on the permits table, with a stated fee range of $50 to $138. That laws PDF was not read.

## Public list

The Division page Licensed Fishing Guides says it lists fishing guides licensed by the Indiana DNR who take people fishing for hire on public waters. The page says the list was updated October 6, 2026. It is an HTML table, not a download, an API, or a name search. Columns are last name, first name, business name, telephone, and charter locations.

Counted from the table body on 2026-11-25: 69 data rows. The phrase Lake Michigan appears on 32 of those rows. The phrase Michigan City does not appear. One row names Portage. Charter location is a water description supplied for the public list, not a slip, a hull, or a documentation number. One business name is shared by three rows, so a business name is not a hull.

The application checkbox asks whether the applicant wishes to be listed on the Division website. The 69 rows are that opt-in extract. The number of licenses issued is unknown.

## Michigan City departure list

The Michigan City Port Authority charter page, last modified 2026-03-11, lists fishing charters at Washington Park Marina with a captain name and a slip. Twelve fishing listings were counted. One additional block on the same page is a tour and rental operator at the city dock. That block was not included in the twelve.

The page is a marina business list. A slip assignment is a berth. It is not a measured hull, and it is not the fishing-guide license. Two listings use the same captain and two different names, with two slip numbers. Another listing shows two slip numbers under one name. Those were not collapsed into one hull.

Five of the twelve fishing listings were compared with a current first-party site and with the October 6, 2026 opt-in table. Two were supported. Three were held. Sampled = supported + held: 5 = 2 + 3.

The supported pair is one publisher. The page names two hulls, each with a length and a make, and no registration or documentation number. The opt-in table has one person row for that captain and business family. The license does not assign the person to either hull. The port page gives those two names different Washington Park slips.

The three holds were: a bookable Michigan City site that names Washington Park Marina and matches an opt-in person, but does not name a measured hull; a bookable site whose captain is not on the opt-in table and whose boat is described by make class only, with no hull name, length, or documentation number; and a port listing whose published website returned an under-construction page, so no current booking page or hull was available. The last of those still matches an opt-in person. A second captain named on the first held site is not on the opt-in table. Absence from an opt-in list is not a finding that someone is unlicensed.

Seven fishing listings on the port page were not opened as first-party booking pages. One linked hostname did not resolve and was left outside this five-row sample. The full Michigan City fleet is not the twelve, and it is not the 32 Lake Michigan opt-in rows.

## Commercial reuse

A current public list, a right to copy it into a commercial directory, and authority to claim a listing are separate.

- IN.gov terms of use (https://www.in.gov/core/terms_of_use.html) allow viewing, printing, or downloading portal content only for personal use, not for republication, distribution, sale, or derivative works, except as law including the Access to Public Records Act otherwise allows. Copyright notices must stay intact. The terms also prohibit using the portal to exploit material for advertising or commercial purposes. That is not a directory grant. The Access to Public Records Act text was not opened.
- The application checkbox authorizes a listing on the Division website. It does not mention a third-party directory.
- The Port Authority legal notice (http://www.mcmarina.org/legal.htm) allows display, print, or reproduction for personal, non-commercial use only. Other use needs written consent. No attribution formula for a commercial directory is stated.
- Operator pages checked here either reserve rights in a copyright line or say nothing. Silence is unknown. A copyright line is not a directory grant.

No bulk feed other than the HTML table was found. Nothing checked here authorizes this directory to claim a listing.
